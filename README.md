### Project Summary

**🚗 FaultMon**  
실무에서 경험한 차량 고장 관제 시스템을 개인 프로젝트로 재구현했습니다.  
기존 .NET MVC 통합 구조에서 **React + ASP.NET Core API + SignalR** 구조로 리뉴얼했습니다.  
[Frontend](https://github.com/leesein1/FaultMon-Front) · [Backend](https://github.com/leesein1/08.SeinServices.Api) · [Legacy V1](https://github.com/leesein1/FaultMon)

**🏡 Chungyak Manager**  
매일 직접 확인하던 청약 공고를 자동 수집·동기화하고, 변경/마감/알림까지 이어지도록 만든 서비스입니다.  
React 프론트와 공용 ASP.NET Core API 서버를 분리해 운영하는 구조입니다.  
[Frontend](https://github.com/leesein1/chungyak_manage_web) · [Backend](https://github.com/leesein1/08.SeinServices.Api)

**⚙️ Monthly Excel**  
반복적인 Excel·웹 업무를 줄이기 위해 만든 WinForms 자동화 프로그램입니다.  
실제 사용 흐름을 기준으로 크롤링, Excel 처리, 이미지 작업, 배포/업데이트 기능까지 확장했습니다.  
[Repository](https://github.com/leesein1/Monthly_Excel)

**💍 Wedding Template**  
실제 사용을 목적으로 제작한 React + TypeScript 기반 모바일 청첩장입니다.  
모바일 UX를 중심으로 갤러리, 지도, 카운트다운 등 실제 서비스 기능을 구현했습니다.  
[Repository](https://github.com/leesein1/wedding-template)
